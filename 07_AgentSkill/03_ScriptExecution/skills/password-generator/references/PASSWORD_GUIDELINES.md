# 密码生成指南

## 通用规则

- 不要在不同服务之间重复使用密码。
- 始终使用密码学安全的随机源（例如 `random.SystemRandom()`）。
- 避免使用词典单词、键盘规律（如 `qwerty`）、以及个人信息。

## 按使用场景推荐设置

| 使用场景             | 最小长度 | 字符集                           | 示例                     |
|----------------------|----------|----------------------------------|--------------------------|
| Web 账号             | 16       | 大写 + 小写 + 数字 + 符号        | `G7!kQp@2xM#nW9$z`       |
| 数据库凭据           | 24       | 大写 + 小写 + 数字 + 符号        | `aR3$vK8!mN2@pQ7&xL5#wY` |
| Wi‑Fi / 网络密钥     | 20       | 大写 + 小写 + 数字 + 符号        | `Ht4&jL9!rP2#mK7@xQ`     |
| API key / token      | 32       | 大写 + 小写 + 数字（不含符号）   | `k8Rm3xQ7nW2pL9vT4jH6yA` |
| 加密口令（passphrase） | 32     | 大写 + 小写 + 数字 + 符号        | `Xp4!kR8@mN2#vQ7&jL9$wT` |

## 符号集

- **标准符号**：`!@#$%^&*()-_=+`
- **扩展符号**：`~`{}[]|;:'",.<>?/\`
- **安全符号**（URL / Shell 安全）：`!@#$&*-_=+`
- 如果目标系统对符号有限制，请仅使用 **安全** 符号集。
